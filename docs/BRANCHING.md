# Branch Naming Conventions

## Format

```
<type>/<issueNumber>-<scope>-<short-description>
```

- `type`: The purpose of the branch  
  - `feature`, `bugfix`, `hotfix`, `docs`, `test`, `chore`, `refactor`, `ci`
- `scope`: Area of the code or concern (e.g., `cli`, `sync`, `auth`, `db`, `labels`, etc.)
- `description`: A short, kebab-case summary of the feature/fix/thing being worked on

### Examples

- `feature/64-docs-structure`
- `bugfix/71-sync-date-parsing`
- `docs/88-cli-usage-guide`
